# Chessport

لعبة شطرنج عربية محلية قابلة للتثبيت كتطبيق PWA على Android وiPhone.

## التشغيل

افتح `index.html` أو انشر المستودع باستخدام GitHub Pages. يجب استخدام HTTPS حتى يظهر خيار التثبيت.

- Android: افتح الرابط في Chrome ثم اختر **تثبيت التطبيق**.
- iPhone: افتح الرابط في Safari ثم **مشاركة → إضافة إلى الشاشة الرئيسية**.

اللعبة الحالية تعمل على نفس الجهاز، وتدعم المؤقت، النقلات القانونية الأساسية، الترقية، الكش مات وقلب الرقعة.
